Small Java Starters

A collection of small Java programs written while learning core language concepts — control flow, arrays, randomness, and basic simulations of real-world systems. Built incrementally over a few weeks as practice.

Projects:
File - 	What it does
banking.java - 	Simulates basic bank account operations (deposit/withdraw/balance tracking)
ShoppingCart.java - 	Simulates adding items to a cart and calculating totals
telephoneBasicLayout2DArray.java - 	Renders a basic telephone keypad layout using a 2D array
calculator.java - 	Simple arithmetic calculator
compoundInterest.java - 	Calculates compound interest from principal, rate, and time
tempConverter.java - 	Converts between temperature units, using the ternary operator
weightConverter.java - 	Converts between weight units
quizGame.java - 	A simple multiple-choice quiz game
countdown.java - 	A basic countdown timer/program
numGuessGame.java - 	Number guessing game against a randomly generated target
RockPaperScissorsGame.java - 	Classic Rock, Paper, Scissors against the computer
diceRoller.java - 	Simulates rolling a die
slotMachine.java - 	Simple slot machine simulation using randomness
RandomClass.java - 	Coin flip simulator, exploring Java's Random class

What This Repo Represents:

Early, hands-on practice with Java fundamentals — conditionals, loops, arrays (including 2D arrays), and basic object-style simulations — before moving on to larger structured projects.

How to Run:

Each file is self-contained. Compile and run individually, e.g.:

bash
javac banking.java
java banking
